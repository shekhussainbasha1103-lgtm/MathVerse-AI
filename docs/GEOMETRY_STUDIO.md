# Geometry Construction Lab

The upgraded Geometry screen adds a construction-tool catalogue and a vector drawing board for the web and Expo Android app.

## Included in this stage
- Basic construction presets: line, segment, angle, angle bisector, parallel line, perpendicular line and perpendicular bisector.
- Triangle families and quadrilaterals: triangle, right/isosceles triangle, quadrilateral, rectangle, square, rhombus and trapezium.
- Circles and conics: circle, arc, tangent/secant illustration, circumcircle/incircle illustration, ellipse, parabola and hyperbola.
- Regular polygons: regular polygon, pentagon, hexagon and octagon.
- Locus curve illustration and engineering-drawing presets (orthographic view, isometric axes, dimension line, projection lines and section hatch).
- Virtual instrument overlays/toggles for compass, ruler, protractor, set square, pencil, eraser and measurement.
- Construction history with previous/next, play, pause, replay and 0.5x/1x/2x/4x playback speed.
- Clear board and construction count/progress display.

## Current-stage limitations
This is a functional visual prototype with selectable preset constructions. It is not yet a full CAD/GeoGebra replacement: points are not yet draggable, the tools do not yet accept arbitrary user coordinates, and the instrument/measurement controls are currently visual workspace controls rather than calibrated physical-scale instruments. Tangent/secant and circle-centre constructions are illustrative presets. The next engineering stage should add pointer/touch drawing, snapping, exact coordinate geometry, constraint solving, calibrated measurement, save/export and construction proof steps.
