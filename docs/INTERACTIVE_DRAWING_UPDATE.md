# Interactive drawing update

This update changes Geometry from preset-only illustrations to a touch/mouse drawing canvas.

## Geometry board
- Select Pencil and drag to make freehand strokes.
- Select Line / Line segment and drag to draw a straight line.
- Select Circle and drag from the centre toward the edge.
- Select Rectangle, Triangle, Ellipse, Arc, or a regular polygon and drag to size it.
- Undo removes the most recent object; Clear empties the board.
- Grid can be shown or hidden.
- Construction tools and engineering drawing presets are available in the tool palette. Some advanced construction entries are currently drawing aids and are not yet mathematically constrained constructions.

## Graphing board
- Enter a function and choose Plot function.
- Tap/click the coordinate plane in Add points mode to place coordinate points.
- Choose Draw line segment and tap/click two positions to join them.
- Zoom in/out changes the graph scale.

## Current limitations
This is the first interactive drawing milestone. It does not yet include persistent saving, calibrated physical ruler/compass/protractor, snapping, draggable existing vertices, exact angle constraints, automated incircle/circumcircle construction, or full step-by-step compass-and-straightedge animation. Those require the next geometry-engine milestones.
