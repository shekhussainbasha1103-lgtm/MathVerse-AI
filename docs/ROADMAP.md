# MathVerse AI — Development Roadmap

## Stage 1 — Foundation (included)
- Cross-platform Expo application shell
- Premium blue/white visual identity
- Dashboard and navigation
- Geometry demonstration board
- Scientific expression calculator
- Basic 2D graph plotter
- FastAPI + SymPy starter API

## Stage 2 — Interactive Geometry Studio
- Draggable points and constraints
- Point, line, segment, ray and circle tools
- Compass, ruler and protractor modes
- Perpendicular and angle bisectors
- Triangle, polygon, tangent and conic constructions
- Live measurements and labels
- Undo, redo, construction timeline
- Save/load project JSON
- SVG/PNG export
- Geometry correctness tests

## Stage 3 — Mathematics Core
- Fractions, percentages and unit conversion
- Linear, quadratic and polynomial equations
- Systems of equations
- Matrices, determinants and eigenvalues
- Complex numbers and vectors
- Limits, derivatives and integrals
- Formula and theorem library
- Step-by-step symbolic explanations

## Stage 4 — Graphing & Visualization
- Multiple functions and parameter sliders
- Zoom, pan and trace
- Roots, intercepts and intersections
- Derivative and integral overlays
- Parametric and polar curves
- 3D surfaces and solids
- Export graph images

## Stage 5 — AI Learning
- AI tutor with age-appropriate explanations
- Camera-based math OCR
- Handwriting recognition
- Diagram understanding
- AI-generated construction instructions
- Answer verification and citations to formulas
- Server-side AI provider abstraction

## Stage 6 — Learning Platform
- Secure sign-up and sign-in
- Profiles and cloud synchronization
- Practice questions and quizzes
- Exam paper generator
- Learning analytics and topic mastery
- Multilingual interface
- Offline saved lessons

## Stage 7 — Engineering & Release
- Technical drawing and dimensioning
- Orthographic projection learning tools
- Automated tests and accessibility
- Security review and privacy controls
- Production deployment
- Android Play Store and Apple App Store preparation
- Web hosting and monitoring

## Release gates
Each stage should pass type checking, unit tests, manual web testing, Android testing and iOS testing before it is called complete.
